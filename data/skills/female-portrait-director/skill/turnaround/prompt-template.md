# 人物角色资产与四视图提示词模板

本模板用于所有年龄、肤色、性别、族裔及虚构种族。花括号由角色简述、显式设置、参考图可见内容或明确标注的创作补全填充；最终出图文本不保留备选项。

## 角色资产表（详细档案；仅姓名、年龄、身高、头身比上图）

```text
编号／姓名：{唯一标识}
身份／时代／世界观：{设定}
年龄／性别表达／族裔或种族：{设定}
肤色：{明度、色调、自然色差}
身高／头身比：{创作设定，不称为图片测量事实}
体型：{肩颈、胸廓、腰腹、骨盆、四肢、身体条件}
面相骨相：{脸部长宽、眉骨眼窝、颧部宽度与高度、颌角下巴}
五官：{眉眼、眼距、鼻梁鼻翼、唇峰唇厚、个人识别点}
发型：{发际线、长度、卷直、发量、分缝、轮廓}
胡须／妆容：{确定设计或无}
服装：{内外层、领袖、衣长、腰线、下装、鞋履}
服装材质及配色：{主色辅色、织物、旧化、固定结构}
配饰与道具：{数量、角色自身左右位置、接触连接或无}
气质／表情／站姿或支撑姿态：{明确的视觉表现}
与各已有角色的差异：{身高、比例、脸、发型、体型、服装至少四轴；包含脸与身体}

```

## 出图正向模板

```text
生成横向16:9、原生{画布宽}×{画布高}像素（整张{画质档次}）的{风格}角色四视图定妆参考图。
优先保持同一角色身份及独特性，再保证布局角度、身体比例、服装结构和材质可读性。

【画面布局】
左至右：正面头像特写（28%宽）；正面全身0°；角色自身{左或右}侧面全身90°；背面全身180°。后三栏等宽，轮廓不重叠，留中性空隙。不是合影，不是四个全身，无额外视图或分隔线。仅开启信息显示时，底部预留约6%高度供一行基础信息。
【人物身份与面部】
{角色年龄身份；脸型骨相、眉眼鼻唇、个人识别点；明确表情。不能仅写“好看”“东方面孔”。}
【体型与比例】
{身高、头身比、肩颈胸腰胯及四肢。符合年龄和身体条件。不得一律小头长腿、宽肩窄腰。}
【肤色与皮肤质感】
{确切肤色、局部色差、适龄纹理。四视图白平衡统一，不漂白或磨皮。}
【头发与妆容】
{发型正侧背轮廓、发色、胡须、妆容。改变妆容不改变骨相和肤色。}
【服装】
{一套确定服装的结构、版型、材质、配色、旧化。背面合理延续前面裁剪，不随角度换装。}
【配饰、道具与鞋履】
{固定数量和自身左右位置、连接和握持、重力接触。没有则写无。}
【姿态与取景】
特写头顶至锁骨，双眼清楚。三全身同缩放、同头顶高度和脚底基线，头脚衣摆道具留安全边距。{统一姿态或适龄支撑姿态}。侧面严格90°，头胸骨盆同向；左侧鼻尖朝画面左方，右侧反之。背面不回头。
【背景、摄影与照明】
{背景}，统一柔光、补光与接触阴影，暗部有材质、高光不过曝。自然人像与低畸变中长焦观感，镜头水平，全身清楚，不强浅景深，不引入运镜。
【气质与风格控制】
{气质转为眼神、眉口放松程度、体态和材质语言。}
【底部基本信息（可选，默认关闭）】
若关闭，不显示文字、不预留信息条。若开启，底部独立留白居中显示一行：{角色名}｜{年龄}｜{身高}｜{头身比}。简洁深灰字，不遮挡人物，不加其他说明。
【角色区分与一致性】
锁定{骨相五官、比例体型、发型轮廓、服装结构}四类识别点，与已有角色的{具体差异}保持区分。四视图是同一个人同一时刻同一造型，左右配饰不镜像，只有一个特写和三个全身。
```

## 最新体型约束（优先级高于旧示例）

女性身高不得低于170cm，男性不得低于185cm。默认体型为高挑、修长或匀称，禁止矮胖、粗短或圆厚体型。保留年龄和骨相差异，不把身高统一成同一个数值；通过面容、比例、发型与服装建立角色区分。参考图中较低身高不能照搬。明确输入低于下限时，CLI报错，不静默篡改；先修改角色设定再生成。非二元角色无用户指定硬阈值，当前示例采用185cm匀称体型。儿童若按男性/女性身高硬规则设定，明确标注为非常规虚构身高，保留适龄面容、比例与非性化服装。

## 最新默认服饰

默认中国古风、修仙玄幻服饰：丝绸、缎面、织锦、刺绣、玉饰与金银配件。用月白、天青、青玉、朱红、紫金等清晰配色，区分衣型、领襟、袖型、腰封、护肩和披帛。禁止粗麻布、暗灰主配色、灰暗工装及灰暗粗粝风格。摄影棚可为中性浅灰，但服装不得因此变灰。参考例中的大面积露背、透明暴露、固定年轻女性面容、斜背回眸、浅景深不作为通用默认。

画质档次：默认 `2k` → 2048×1152；可选 `1080p` → 1920×1080。尺寸指整张四视图，不是单栏；档次不改变角色或服装设计。工具不可用时保存模板与待出图请求即可，不宣称已生成或已验收。
