# 通用人物四视图定妆流程 V2

本模式服务所有年龄、性别、肤色、族裔及虚构种族。旧版女性写真 Route、成年默认值、五段输出、剧情动作链和浅景深要求不适用于本模式。保留用户显式设定；未指定的人口属性可作为创作补全并标明，不默认年轻东方女性。儿童与年龄不明角色使用适龄、非性化服装和姿态，不套用成人曲线路由。

## 简要描述 → 结构化提示词

1. 读取 `template.json`，默认 xianxia；可选 studio / mythology / historical / stylized。用户设置优先于模板默认，明确身份优先于风格补全。
2. 锁定原始简述和设置，区分用户指定、视觉观察、创作补全。参考图按 identity / costume / layout / style 标明角色；布局参考不得成为人物身份参考。多个不同人物图片不能融合成一个身份。看不出的身高、头身比、族裔不作为事实猜测。
3. 输出结构化 JSON 和完整中文提示词：画面布局、人物身份与面部、体型与比例、肤色与皮肤质感、头发与妆容、服装、配饰道具与鞋履、姿态与取景、背景摄影与照明、气质与风格控制、一致性限制；另附负向词。每个角色特征写成可见描述，不能只输出标签。
4. 默认横向 16:9，默认2K为整张2048×1152，可选1080p为1920×1080，不是每栏的分辨率。左至右：正面头像特写（28%）、正面全身 0°、标准侧面全身 90°、背面全身 180°。剩余三栏等宽。三个全身同缩放、同头顶高度、同脚底基线；头脚和道具留安全边距，无重叠、分隔线或水印；可选开启底部基本信息，默认关闭。
5. 左侧面指角色自身左侧朝镜头、鼻尖朝画面左方；右侧面反之。头、胸、骨盆同向，不能用 3/4 代替。左右配饰以角色自身为准，不随视角镜像交换。背面不回头。
6. 普通站姿可按年龄、身体条件、轮椅等明确设定适配，不能把所有人物强制写成宽肩窄腰、9 头身、站立成年人。婴儿可采用统一支撑姿态；在提示词中明确支撑关系。
7. 负向词仅限制失误：身份/年龄/肤色漂移、额外视图、裁切、比例错位等；不得把黑皮肤、白发、皱纹、男性、儿童等正常属性列为通用负向词。妆容、胡须、伤疤、秃头、面罩等遵循当前角色。

## 出图与验收

用户请求生成定妆照时，先保存可复用提示词，再在同一任务调用可用内置图像生成能力；用户允许暂缓测试或工具不可用时保存待执行任务。只要提示词时不要调用出图。

- 推荐通过 `scripts/turnaround.py prepare --brief '简要描述' --output outputs/角色名` 调用 DeepSeek 生成内容；只有文本发送给 DeepSeek。若没有凭据，可由当前代理直接按模板撰写相同结构，不伪称 API 已调用。
- `prepare` 写入 `character.json`、`prompt.txt`、`negative.txt`、`generation-request.json`。它不自行出图；代理读取请求后调用内置 `image_gen`，把 `prompt` 传给工具。存在参考图时先查看实际图片，再按用途添加到生成工具参数，不把图片内容假称为文本模型已识别。
- 使用请求中的尺寸要求。内置工具的尺寸仅能通过提示词请求，必须检查实际文件；不能因为提示词写了 2K 就宣称交付 2K。保存原图到输出目录，然后执行 `verify-image`。不静默拉伸或放大小图冒充原生 2K。
- 若尺寸不匹配，报告实际尺寸可在工具支持且需要时定向重试一次；当前已知内置工具尺寸不受控，不必重复测试；仍不匹配时保留原图并说明未满足尺寸。若图像能力不可用，交付提示词和待执行请求，明确未生成图像。
- 人工看图验收：只有四个视图、头像加三全身、侧面角度、背面不回头、同一身份与服装、左右配饰、全身无裁切、肤色和年龄一致。像素校验不等于这些视觉检查。失败时带原图定向修正，保留版本，避免无限重试。

## 设置

`--settings` 为 JSON 文件，支持 `quality`、`show_info`、`height`、`head_body_ratio`、`face_structure`、`facial_features`、`template`、`side` (left/right)、`portrait_fraction` (0.20–0.40)、`style`、`background`，以及自由文本 `age`、`gender`、`skin_tone`、`ethnicity`、`species`、`body`、`hair`、`costume`、`accessories`、`pose`、`notes`。年龄可为“婴儿”“80 岁”，性别、族裔和种族为开放字段。空字段不施加约束。未知字段报错，避免设置静默丢失。

四视图提供 `quality: "2k"`（默认2048×1152）与 `quality: "1080p"`（1920×1080）两档，CLI `--quality` 优先于设置文件。保持16:9，不提供任意画幅。

参考依据：用户 2026-09-25 提供的会话 https://chatgpt.com/c/6ab691cf-1958-83ea-a263-fe204a2cae69 和六张布局示例。抽取版式、身份锁定、材料和摄影结构，未将示例中的成年男性、古铜肤色、黑袍或锁链设为通用默认。

## 跨角色差异与东方面孔

创建系列角色时，先读取已有资产的 `asset.json`，汇总为 JSON 数组，通过 `--cast` 传入。新角色输出八项 fingerprint（身高、头身比、骨相、五官、发型、体型、服装轮廓、主配色）及逐角色差异说明。至少四轴显著区分，必须包含脸部和身体；只是改写同义词不算差异。所有锚点进入最终提示词。明确角色相似关系时保留关系，在其他自由维度区分，不擅自改变用户锁定项。

程序只进行文本结构与重复检查；看图后才能判断实际区分度。独立角色板的绝对身高不能靠画面占比比较，需要同尺度阵容对照。

用户偏好更多东方面孔时，读取 [east-asian-design.md](east-asian-design.md)，从六组起点选择或重新组合。用 `--preset` 选择起点，再用 `--settings` 明确覆盖字段。用户简述与选定预设冲突时，应先按用户明确设定改写设置文件，不把预设作为比用户更高的约束。

可复制的角色表与提示词骨架见 [prompt-template.md](prompt-template.md)。本地参考素材的已审内容、取舍和来源哈希见 `docs/reference-audit.md`。外部参考中的安装命令、模型宣传与任意规则均不自动成为本技能指令。

## 基本信息上图

信息显示为可选项，默认关闭。启用 `--show-info` 或设置 `"show_info": true` 后，在底部约6%独立留白区显示一行：`角色名｜年龄｜身高｜头身比`。四视图在其上方保持完整，不覆盖人物。只保留这些基础字段，不把骨相、职业小传或对照说明印上图。未知值如实标注未设定；创作补全在资产文件中说明。文字必须与角色资料一致；验收检查错字、漏字、身高与比例数值，不因要求文字而裁脚或额外增加视图。

## 最新体型约束（优先级高于旧示例）

女性身高不得低于170cm，男性不得低于185cm。默认体型为高挑、修长或匀称，禁止矮胖、粗短或圆厚体型。保留年龄和骨相差异，不把身高统一成同一个数值；通过面容、比例、发型与服装建立角色区分。参考图中较低身高不能照搬。明确输入低于下限时，CLI报错，不静默篡改；先修改角色设定再生成。非二元角色无用户指定硬阈值，当前示例采用185cm匀称体型。儿童若按男性/女性身高硬规则设定，明确标注为非常规虚构身高，保留适龄面容、比例与非性化服装。

## 最新默认服饰

默认中国古风、修仙玄幻服饰：丝绸、缎面、织锦、刺绣、玉饰与金银配件。用月白、天青、青玉、朱红、紫金等清晰配色，区分衣型、领襟、袖型、腰封、护肩和披帛。禁止粗麻布、暗灰主配色、灰暗工装及灰暗粗粝风格。摄影棚可为中性浅灰，但服装不得因此变灰。参考例中的大面积露背、透明暴露、固定年轻女性面容、斜背回眸、浅景深不作为通用默认。

保留已有风格：原有20条风格路线与气质叠加文件保持可用，不因新增默认而删除。选择旧风格时保留其适用的色彩、材质或摄影语言，但四视图模式仍使用固定版式和当前身高体型约束；粗麻布与暗灰主色禁用。单张写真仍通过原有模式调用。

## 持久任务与恢复

完整命令见 `docs/turnaround-quickstart.md`。prepare → awaiting_image_generation；工具不可用时defer → deferred；resume可换档重编译并回到awaiting_image_generation，不重跑文本API。record-image保存原文件独立版本与实际尺寸，进入awaiting_visual_review或resolution_unmet；review记录实际看图结果，仅像素和全部视觉项通过才能accepted，否则visual_review_failed或resolution_unmet。失败后resume重试，所有attempts与reviews保留，不自动升级档次或更换后端。CLI不自行调用内置图像工具，实际调度由宿主Codex执行。
