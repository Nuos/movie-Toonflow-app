# 角色与资产管理

角色与场景页左侧新增“上传本地图片”和“资产管理 / 归档箱”。单个资产的配置抽屉中新增上传、图片管理、归档资产及永久删除资产入口。

- 上传可新建角色、场景或道具，也可在单个资产中新增历史图片。支持PNG、JPG、WebP，最大20MB、解码像素上限4000万；保存实际图片为PNG。上传后设为当前图片，仅新上传图片的提示词初始为空，不调用生成模型；原有图片保留。
- 归档资产后从常用列表隐藏，归档箱可恢复；保留已有制作引用。历史图片也可单独归档、恢复。归档当前图片会取消其当前选中状态，恢复后可手动“设为当前图片”。
- 永久删除资产会清理资产树、图片历史、相关绑定及复现记录；永久删除图片仅针对该版本。删除前显示不可恢复提示。仍被其他素材引用的文件保留；生成中资产须先等待或取消任务。
- 永久删除不清理用户自行导出的文件或既有数据库备份，也不改写已完成的视频。

实现：src/extensions/assetManagement.ts；data/web/asset-management.js；安装入口脚本scripts/install-asset-management.cjs。归档字段由服务启动时幂等迁移。此项目只有打包前端，安装脚本针对明确锚点执行，锚点不匹配时退出。

验证：tests/asset-management.integration.ts在隔离数据库及文件目录验证上传、空提示词、历史保留、图片/资产归档恢复、在用列表筛选、当前图选择、跨项目拒绝、伪图片拒绝、生成中保护和永久删除文件。另执行TypeScript检查、构建和现有删除回归测试，并检查真实页面的新建上传、归档箱与历史图片入口。不在实际项目执行测试删除或生成任务。

每张图片独立保存提示词（o_image.prompt）。切换历史图片同步显示该图提示词；修改抽屉提示词只保存到编辑时对应图片。图片管理中也可逐图编辑并保存。上传、重新生成前保留原图提示词，生成占位记录保存本次提示词。o_assets.prompt 作为当前图的编辑投影保留兼容。前端补丁安装脚本为 scripts/install-image-prompts.cjs。

旧数据仅依据相同资产和图片文件的备份、生成记录或原当前图提示词恢复；未知历史提示词保持未知，不猜测。恢复脚本 scripts/recover-image-prompts.py 应先备份数据库再运行。

同一人物的长期造型使用主角色及命名派生资产，例如“西西弗斯·国王装”“西西弗斯·推石囚服”，分镜绑定相应派生资产并引用其图片；历史图片用于同一造型的版本选择。临时神情通常写在分镜提示词中即可，不必新增人物。仅在提示词中写名字不等于绑定参考图。
