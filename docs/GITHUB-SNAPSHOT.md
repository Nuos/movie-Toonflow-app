# 本地部署版本提交说明

本分支保存 2026-09-29 的 Toonflow 1.1.8 本地部署版本。远程 master 使用另一套 apps/packages 架构，且与原本地 Git 历史无共同祖先，因此以独立根提交保存本版本，不覆盖 master，也不导入旧本地提交历史。

## 提交范围

包含应用源代码、已部署网页与服务入口、供应商适配器、提示词与技能、运镜/H3/分镜/人物/素材管理模块、桥接程序和必要工作流、测试源代码及文档。data/serve/app.js 与 data/web 是当前部署直接使用的运行资源，保留入库。

不包含私有环境配置、API 密钥、数据库、用户生成媒体、复现快照、模型权重、下载与运行环境、日志、缓存、备份、临时结果和个人测试片。local 仅按 .gitignore 白名单保留运行桥接源码和模板。

## 本机配置

文本 API 密钥仅从本机私有文件 /home/ubuntu/.config/llm/deepseek.env 读取，禁止复制到仓库。部署到其他主机时需自行提供私有配置，并调整 systemd、ComfyUI 工作流和工具路径；详细依赖见 LOCAL-DEPLOYMENT.md。本仓库不是包含数据库及模型的整机备份。

模型文件保存在 /home/ubuntu/llmspace/LLM-Model/Playtime-AI 下，data/models 的本机兼容链接不入库。部分集成测试依赖本机私有数据库备份与服务，不属于可直接在全新克隆中运行的独立测试；不要为了运行测试提交这些数据。
