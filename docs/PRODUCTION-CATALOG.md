# 剧目素材编号与固定目录

每部剧使用 `DR-{项目ID}`，场景、角色、道具、音频、视频、剧集和镜头使用同一前缀。记录编号采用数据库原始 ID，补齐到至少六位，不随名称、排序或镜头位置变化。

| 类型 | 编号后缀示例 |
| --- | --- |
| 角色 | `CHR-000018` |
| 场景 | `SCN-000023` |
| 道具 | `PRP-000027` |
| 音频 | `AUD-000101` |
| 视频 | `VID-000102` |
| 剧集 | `EP-000001` |
| 镜头 | `SHOT-000002` |
| 其他资产 | `AST-000103` |

本机剧目素材唯一物理根目录：

`/home/ubuntu/workspace/project/nuos/movie-Toonflow-app/data/oss/productions/`

每部剧分别存入 `DR-{项目ID}/`，按 `assets/characters`、`assets/scenes`、`assets/props`、`assets/audio`、`shots/frames`、`shots/clips`、`videos`、`editing`、`media` 分类。文件名包含剧目编号、媒体类别和原路径的稳定摘要，保留扩展名，避免同名覆盖；资产编号和对应文件路径由清单关联。新增媒体经统一 OSS 写入函数自动归档。

共享音乐和音效保持在唯一的 `data/oss/library/audio/`，由各剧的音频资产编号引用，避免复制相同素材。旧剧目路径保留相对符号链接，用于兼容原数据库引用和收藏链接，不另存重复文件。用户原资产名称与数据库 ID 保留。

在运镜效果区域展开“选择实际引用素材”，可以查看编号、固定目录，点击“导出本剧编号与目录清单”更新该剧 `catalog.json` 并下载清单。清单按导出时的数据生成；编辑器的编号列表始终从当前数据库读取。

## 提示词中的编号

点击“编辑提示词”，输入 `@` 后可按名称、编号或 ID 筛选当前剧的资产与镜头，本镜关联资产优先。方向键选择、回车插入、Esc 关闭。编号不属于当前剧或已删除时，预览会拒绝提交。

选择了实际参考媒体的编号会按引用顺序转成模型对应的图片、音频或视频标签。未选择媒体的编号只展开为名称和描述，不会冒充已经上传的参考图。编号选择与实际媒体选择分开，最终以“本次提交预览”为准。

## 迁移与恢复

`scripts/organize-production-media.ts` 默认只输出计划；加 `--apply` 才执行迁移。迁移前确认没有媒体任务运行，备份数据库与部署程序，停止服务后整理，再启动服务。工具逐个检查大小和 SHA-256，相同内容才建立兼容链接；遇到目标内容冲突会停止。

本次计划、执行清单、验证结果位于 `local/production-media-plan.json`、`local/production-media-migration.json`、`local/production-media-verification.json`，备份路径记录在 `local/prompt-editor-backup-path.txt`。恢复时先停止服务，按迁移清单逐项核对哈希，移除旧路径的符号链接并将对应物理文件移回；存在新写入内容时不得以旧备份覆盖。仅回退程序时，旧程序仍可通过兼容链接读取素材。
