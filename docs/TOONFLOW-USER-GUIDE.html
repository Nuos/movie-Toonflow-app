01 开始使用

  1. 打开 本机 Toonflow，进入“我的项目”。
  2. 继续已有项目时，先点击对应项目；新创意使用“新建项目”，填写名称，并选择适合的视觉风格和导演手册。
  3. 确认画幅与创作目标，例如竖屏 9:16、每集时长、集数和受众。跨阶段保持这些要求一致。
  4. 进入项目后，再使用“小说原文”“剧本规划”“剧本管理”“角色与场景”“制作工作台”“资产库”。主侧栏的创作入口会沿用当前项目。
操作前看清页面顶部项目名与当前剧集。未选项目时先返回项目列表选择，避免在错误项目中修改或生成。

03 创意、原文与事件分析

  1. 在“小说原文”使用上传向导导入文本，核对解析出的章节，勾选需要的章节后保存。
  2. 确认正文完整，章节顺序正确。不要仅凭章节标题或摘要判断原文已全部读取。
  3. 执行事件分析，等待完成后检查摘要是否覆盖整个故事。长篇或多集资料尤其要检查后半部分。
  4. 如需修改章节标题、正文或事件摘要，通过原编辑入口保存，再重新打开核对。

进入编剧前确认：创意来源、计划集数、人物关系、核心反转、结局以及不可删除的台词或情节。

界面截图并不等于创意正文。如果输入只是截图，应另提供创意文本，或明确使用哪份已有资料；不要让模型凭截图臆造完整故事来源。

04 AI 编剧与剧本管理

推荐操作顺序

  1. 故事骨架：进入“AI 编剧”，点击开始规划或在原对话区提出需求。等待骨架进入右侧区域及审核完成。
  2. 改编策略：确认骨架后继续策略阶段，明确节奏、删改、视觉表达和每集功能。
  3. 分集剧本：确认策略后按集或按批生成。页面可能要求分批确认，不要重复发送相同生成请求。
  4. 编辑和审核：用对应区域的“编辑”修改内容并保存；核对集数、集名及正文。AI 请求提交后等待其实际完成。
  5. 剧本管理：进入六集或目标集数列表，确认每集存在；提取资产并核对逐集关联。
示例指令：
请读取完整原文，按6集规划。先生成故事骨架并保存，保留既定人物关系、反转顺序和结局。
本阶段先不生成图片或视频，完成后等待确认。

根据实际创意修改集数。示例用于分阶段控制，不代表所有项目都应制作六集。

生成流中出现文字不等于保存完成。阶段结束后检查右侧内容与剧本列表；关键编辑保存后重新打开一次，确认没有丢失。

05 角色、场景与道具

  1. 从剧本提取基础资产，检查名称、分类、描述及关联剧集。
  2. 编辑角色描述和图像提示词，再选择图片模型、输出比例和规格。
  3. 提交生成后到任务列表跟进；完成后回到资产查看图片历史，选择要使用的版本。
  4. 确认人物脸型、发型、身材、年龄感与服装；角色间必须能独立辨认，同一角色不同状态保持身份一致。
  5. 需要上传已有素材时，在资产库使用对应新增/上传入口，上传后核对文件、名称、描述与备注。

保持连续性

  • 角色：为每个人写清独有骨相、发型与体型，不能只靠换衣服区别。
  • 场景：固定地形、光线方向、建筑或地标和人物行进轴线。
  • 道具：固定形状、材质、尺寸及与人物的比例；剧情变化另作状态描述。
  • 衍生状态：推石、跪地、回忆衣着等状态应参考同一基础角色，避免生成另一个人。
对本次西西弗斯项目：完整巨石为直径约5—6米的近正球体，约人物站立身高三倍；前期无手印、符号或金光。碎石状态不能机械套用完整球体尺寸。

06 导演计划、衍生资产与智能分镜

  1. 选择当前剧集，在“制作工作台”通过原对话流程生成导演计划。
  2. 在导演计划区域检查场次、人物位置、情绪变化、动作与声音，编辑后保存。
  3. 分析衍生资产：仅为剧情需要的状态制作对应素材。进入衍生画布，检查参考连线、提示词和比例，生成完成后明确保存。
  4. 生成分镜表。核对每镜画面、时长、景别、运镜、台词、音效及引用资产；把各镜时长相加检查总时长。
  5. 确认后转换为分镜面板，检查镜头数量、顺序和时长是否与表格一致。
  6. 通过分镜编辑入口修正提示词和视频描述，保存后重开核对；选择镜头后生成分镜图。
  7. 检查分镜图中的人物、空间、道具比例及故事阶段，再送入视频工作台。

理解“@图N”

原分镜图片提示词中的 @图1、@图2 等对应该分镜保存的资产关联顺序，不是整个资产库列表顺序，也不是人物编号。先核对关联资产再写引用。

运镜辅助切片会把编号解析为明确资产，再按实际输入顺序生成视频引用编号。例如本次 S01：图1=推石态，图2=巨石，图3=惩戒山·山道。这个映射仅适用于该分镜，其他分镜必须各自核对。

名称声明与原关联冲突，或编号不存在时，页面会报错并禁用切片生成。修正引用后重新准备；不要通过随意替换编号绕过错误。

07 原视频生成与任务跟进

  1. 点击“打开视频工作台”，选择当前镜头/轨道，核对视频提示词与参考素材。
  2. 选择已配置的工作流、输入模式、时长、分辨率、画幅以及声音设置。可选参数以当前工作流实际支持项为准。
  3. 核对引用顺序，尤其是首尾帧；确认人物状态、画面方向与运镜要求没有相互矛盾。
  4. 点击生成后记录对应任务，到任务列表查看进展。可以离开生成界面处理其他事项。
  5. 完成后回原工作台打开历史结果并播放。检查文件是否正常、画面与声音是否符合镜头要求。
  6. 失败时先查看具体错误和任务状态，再决定修正配置或重试；不要因页面暂时未更新就重复提交。
模式适用情况重点核对
T2VA以文本生成视频无图像约束时，人物身份一致性不能保证
I2VA以一张图作为主要画面依据参考图是否为正确角色、姿态与场景
FL2VA以首帧和尾帧控制起止画面两图顺序、空间连续性及运镜是否兼容
Ref2VA使用多种参考素材数量上限、素材类型、输入顺序与提示词引用

品质、加速、Turbo、标准等规格在速度和输出表现上可能不同。真实成片时长可能因工作流帧数对齐略有差异，最终以生成文件为准。

“任务完成”说明生成请求产出结果，不代表镜头艺术质量通过。对白是否多读说明、角色是否漂移、画面是否连续，需要实际观看与听辨。

08 辅助工具怎样接入原流程

提示词与复现

选择同一项目及对应资产或视频片段，建立候选提示词并检查主体、风格、构图、连续性和引用。建组不会自动替代原内容；采用后回原编辑器检查保存结果。人工修改的主体描述需要自行复核，系统不会把所有历史文本一律覆盖。

声音与影视配乐

按角色年龄、性格和表演选择音色，试听后再使用。背景音乐按场景功能选择；可以加入古琴、笛箫、二胡、琵琶或戏曲声腔等方向，但先核对当前素材库实际可用内容。避免对白、环境音与配乐互相遮盖。素材来源及使用许可应在需要发布时核对。

镜头与运镜

  1. 选择项目、剧集和原分镜，核对自动带入的故事内容。
  2. 填写起幅、落幅、主体动作与叙事目的，再选择主要运镜、景别、机位、幅度和节奏。
  3. 建立候选并比较。几何动画只解释摄影机路径，不是生成视频。
  4. 采用方案时勾选目标：分镜描述、分镜图提示词、视频提示词。确认只更新需要的字段。
  5. 独立切片区会匹配引用与工作流，显示准备结果；只有点击“生成此运镜切片”才提交视频任务。切片独立保留供比较。
  6. 出现冲突提示时先修正正文和引用；准备成功后再检查实际输入素材与顺序。
辅助工具用于补充已有创作内容。采用前读清目标，采用后回原模块检查；不要用辅助页面代替原剧本、分镜和视频工作台的保存与确认。

09 整理、剪辑与交付

挑选已通过画面和声音检查的镜头，整理素材名称、镜头顺序和版本。需要剪辑时可在原工作台进入剪辑页，使用视频、媒体、图片、音频、字幕、转场、特效及滤镜入口。

  1. 将素材添加到时间线，核对顺序、时长和音量；滤镜属性可编辑强度、色相角度或模糊半径。
  2. 使用“保存剪辑草稿”；多个页面编辑同一草稿发生冲突时，先重新打开最新版本，不强行覆盖。
  3. 使用“导出视频”，完成后可预览、下载或“保存到项目素材”。
  4. 最终交付前完整播放一次，核对画幅、字幕、黑场、音量、台词以及开头结尾。

本次工作已按用户要求结束剪辑模块测试。保留的测试草稿与素材574用于功能验证，不是正式成片；本文只保留使用说明，不表示继续执行剪辑测试。

10 注意事项与常见问题

现象处理方式
创作入口要求选择项目回“我的项目”选择正确项目后再进入。
AI请求失败查看具体提示。余额不足、鉴权失败、限流分别处理；恢复后先核对上次任务是否完成再重试。
图像或视频一直等待查看任务列表及对应服务状态；暂时观察不到进度不等于失败，不重复提交。
参考图片不可用或类型错误检查资产是否已有可读文件，当前引用版本是否正确，输入模式是否支持该素材类型及数量。
@图N名称冲突核对原分镜关联顺序和具名声明，统一二者；缺失编号重新选择资产卡片。
切换镜头后参数不符确认当前轨道、工作流与保存值；切换规格后重新核对参考和时长。
生成结果人物不同或朗读动作说明检查角色参考、输入模式和台词标注，缩短有歧义的表演说明；更换参考或重写提示词后再决定重试。
图片比例不对检查输出比例与规格，参考图比例不等于输出比例；保存后检查实际结果。
冷色滤镜把肤色变蓝当前预设是色相旋转，可调整角度或去掉该预设；不能把明显变色当作自然冷调。
导出草稿被另一页面更新重新打开最新草稿后继续，避免并行覆盖。
服务更新后仍显示旧效果完整刷新页面；同一单页路由内跳转可能不会重新加载脚本。
  • 保存重要版本后再做大幅修改。不要删除唯一已确认的角色或参考图片。
  • 角色、道具状态和原文设定的修改应同步核对后续镜头，而非只改一处提示词。
  • 图片、视频、声音分别使用其服务配置；DeepSeek文本余额恢复不表示其他服务的额度也恢复。
  • 不要把密钥写进提示词、前端、截图、文档或Git。文本服务复用本机已有私有配置。
  • 正式发布前另做内容、声音和素材许可检查；功能测试通过不能替代这些检查。
