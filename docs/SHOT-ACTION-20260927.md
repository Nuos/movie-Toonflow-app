# 完整动作分镜优化与两镜验证（2026-09-27）

本轮基于截图对应项目“原流程验收-西西弗斯-20260924”中第一集原剧本，新增独立测试剧集“动作优化测试·第一集开场两镜·20260927”。只测试开场推石失败与查看双掌两个完整动作。原有整集分镜未批量改写。

## 功能与模板修改

- 分镜表、面板写入模板按“本镜主题、起始画面、主体动作、结束画面、摄影机、台词与声音、连续性”组织。删除旧模板强制以新动作起始态收尾、旁白按字数拆碎、英文摄影缩写等冲突要求。
- 新增分镜、批量导入、视频时长及视频提交限制为 8 至 15 个整数秒。批量分镜使用独立轨道；拒绝重复轨道编号，不把新镜头并入旧轨道。已有短镜仍可阅读，重新生成提示词前要求按完整动作重新编排，不自动拉长原文字或修改全剧。
- 每镜最后至少两秒明确手位、身体支撑、目光目标与自然呼吸；模型规则禁止无剧情依据的突然恍惚、茫然和新动作。文字规则不能保证任意模型每次都遵循，实际输出仍需检查。
- 自动识别结构化分镜中的主题、主体动作、结束画面和连续性，带入镜头设计表单。
- 单个、批量视频提示词生成检查镜号、引用槽位、引号内台词与旁白、小数时间、简略词和摄影缩写。首次不合格时用具体错误纠正一次；仍不合格则保留旧提示词。
- 修复已采用运镜时，标准化过程用旧摄影模板覆盖新模型动作正文的问题。保留原始动作细节与真实参考素材绑定。
- 画幅同步支持“16:9 横画幅”等写法；引用台词不被参数同步改写。声线说明改用中文，并明确声音年龄不得改变可见人物身份。
- 已生成切片增加“删除切片”。只删除本分镜所属、已完成或失败的切片记录与对应文件、私有请求归档和准备令牌；保留原分镜、视频轨道、参考资产。运行中或状态未确认的任务不能删除。
