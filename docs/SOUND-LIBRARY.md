# Toonflow 本地声音与影视配音、配乐

当前版本包含 102 项实际音频。2026-09-27 新增 21 项经典影视、自然声与电流特效，均有真实本地音频及来源记录。进入项目音频资产或点击“加入项目音频资产”即可同步新增素材。

## 使用

- 项目左侧点击“声音与影视配音”，按类型、乐器、性别、年龄或性格检索、试听和下载。
- 人物卡片 → 单独配置 → 默认声线：选择后自动保存并关联本地音频；可进入完整声音库试听后再选择。场景及道具面板提供环境声和动物声音。
- 每个项目的原“音频参考”选择器和资产中心也可检索这些素材。新项目首次打开音频资产时自动导入，或在声音库选择项目后点击“加入项目音频资产”。重复导入不会复制文件或创建重复条目。
- 影视配乐提供最长 30 秒试听、完整 WAV 和下载源音轨。可用于后期剪辑配乐；声音库不会把配乐设成人物声线，也不会自动修改现有成片。
- 原人物设定不会被自动覆盖。衍生角色未绑定独立音频时继承主角色；单独选择后覆盖继承。清除内置预设会保留独立上传的参考音频。

## 本地存储与来源

实际素材根目录：`/home/ubuntu/workspace/project/nuos/movie-Toonflow-app/data/oss/library/audio`。

- `voices/`：46 份中文 WAV 与逐项生成记录。
- `effects/`：16 份环境/动物 WAV。
- `music/`：19 份完整双声道 WAV（初批器乐 24kHz，新增戏曲 48kHz）；`previews/` 为 MP3 短试听。
- `originals/`：下载的源音轨和音效包；下载源音轨可保留源文件的编码与采样率。
- `licenses/`、`sources.json`、`CREDITS.md`：作者、来源、许可和处理说明。
- 仓库 `data/audio-library/`：界面目录、声线设计、配乐下载来源及校验值。

文件由多个项目引用，不为每个项目重复复制；从一个项目删除音频资产不会移除公共源文件。显式重新选择某预设时会修复该项目已删除的对应音频版本。

外部素材采用 CC0、CC BY 或 CC BY-SA，逐项许可见本地 `CREDITS.md`，使用 CC BY 素材应保留署名与改动说明；豫剧现场录音采用 CC BY-SA 3.0，相应改编需遵循相同许可。本地生成声线保留模型许可记录；模型许可不等于对生成结果的版权承诺。

声线由 Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign 生成，固定版本 `5ecdb67327fd37bb2e042aab12ff7391903235d3`。模型实际存放在 `/home/ubuntu/llmspace/LLM-Model/Playtime-AI/models/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`，未把权重放进 Toonflow。运行依赖在本项目 `local/qwen-runtime`，复用本机已有 Python/torch，不改动 ComfyUI 工作流。

## 维护与验证

本地音频已准备完成，日常使用无需再次生成或联网下载。仅在补充或修复素材时按需运行：

```bash
python3 scripts/download-library-music.py
python3 scripts/expand-sound-library.py
python3 scripts/prepare-sound-library.py
node scripts/install-character-voices.cjs
```

下载脚本复用已有源文件并核对校验值；整理脚本需要本机 `local/audio-tools` 内的 py7zr。`scripts/generate-local-voices.py` 仅用于主动制作缺失的声线样本；现有样本和生成记录会跳过。不要将它作为日常启动步骤。

前端独立文件为 `character-voices.js`、`sound-library.html/js`、`sound-library-entry.js`。主前端只有编译产物，升级后用安装脚本恢复入口；结构不匹配会报错。后端修改后运行类型检查、构建，并在没有生成任务时重启用户服务 `llmspace-toonflow.service`。

历史验证包括：81 个基础音频解码及校验值、46 份声线不同文件、全量本地链接和 19 个短试听读取、页面筛选与真实播放、隔离项目中的保存关联、父角色继承和子角色覆盖、静音与不支持音频参考的模式过滤、跨项目隔离、重复导入和删除后的修复。单条与批量视频链路通过模拟生成调用验证真实音频字节传递，未重新生成用户影片。

测试：`tests/character-voices.test.ts`、`tests/character-voices.integration.ts`、`tests/sound-library.integration.ts`。部署核验记录：`local/sound-library-audio-validation.json`、`local/sound-library-live-verification.json`。修改前备份：`local/backups/audio-library-20260922T055356Z/`。
