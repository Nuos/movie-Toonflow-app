# 分镜资产预览

2026-09-27 更新。入口：影片制作 → 视频工作台 → 资产预览。

## 功能

- 顶部为带文字和键盘操作的「资产预览 / 视频生成 / 视频剪辑」入口，后两项保留原工作流。
- 图片页优先显示分镜成图，允许查看全部关联角色、场景和道具参考图。没有成图时展示真实参考图并标明来源，不回写分镜图片字段。多参考图在底部以组合缩略图展示。
- 视频页接入同项目、同剧集轨道的成功视频版本、当前用户已完成的运镜切片和关联视频资产。采用版本优先；未采用版本仅用于预览，不改变工作台选择。
- 轨道视频按原分镜顺序和计划时长累计起止点，播放限制在该时间段内。视频短于计划时截到实际片尾；起点超出源时长则提示错误。该时间段是计划切片，不进行自动语义镜头识别。
- 支持播放/暂停、前后镜、进度定位、原文件和全屏查看、搜索镜号/描述/资产、媒体筛选、多选、拖动/按钮排序和还原。排序仅在本次预览有效。
- 提示词和画面描述可展开复制；预览不调用文本、图片或视频生成模型。
- 图片导出包含所选分镜的成图与参考图，按来源分目录、同源去重。视频导出使用每镜预览选择的版本；轨道视频经本机 FFmpeg 导出独立 MP4，运镜切片与视频资产保留原文件。附素材清单及缺失/失败报告，不导出空 ZIP。
- 导出切片需要本机 ffmpeg / ffprobe，单镜上限 120 秒、同时转码最多两项；仅接受数据库内匹配分镜的本地视频文件，临时文件发送完成后清理。

## 实现

- `src/routes/production/getStoryboardData.ts`：原接口保留旧字段，新增图片/视频集合及状态；子路由 `/slice` 输出独立视频切片。
- `src/utils/storyboardVideoSlice.ts`：轨道关系、路径检查、时长探测及切片导出。
- `data/web/storyboard-preview.js` / `.css`：独立预览组件。
- `scripts/install-storyboard-preview.cjs`：幂等安装到现有打包前端，仅替换预览组件；以真实文档末尾的 head 标记插入资源，避免匹配包内字符串。
- `src/app.ts`：OSS 原文件开启 HTTP Range，以支持视频随机定位。
