## 三个既有失败

对照测试移除了本次 `generationRecipe.ts` 中的人物定妆逻辑，保留原有项目代码与测试数据，以下相同失败仍可复现。未为使报告全绿而改写这些断言或修改相关既有业务行为。

- `character-voices.integration.ts`：提示词结果中缺少断言要求的“低沉男声”。
- `original-image-adapters.integration.ts`：旧测试期待 `ensureAssetBaselines` 对缺失基准文件拒绝，但既有代码已不自动创建/加载辅助基准。
- `original-storyboards.integration.ts`：旧测试期待自动存在辅助提示词标准，读取不存在记录的 `data` 失败。

对照日志位于 `local/portrait-integration-20260925/baseline-*.log`；对照生成配方源码快照为 `baseline-generationRecipe.txt`。Agent工具数与角色输出格式相关测试已按新增工具及结构化模板更新，保留原有隔离、错误处理与取消断言。

## 尚待通过的验收

- 稳定生成严格“头像＋正面全身＋90°侧面＋180°背面”的四栏，消除额外视图。
- 年龄与身份细节、左右配饰、服装一致性达到完整人工视觉要求。
- 参考图字段修改时维持原图背景与材质质感，避免过度锐化。

此前驱动缺失导致一次实际Qwen提交连接失败，保留该历史失败。当前驱动已恢复；健康检查仍保留，离线时不会创建图片占位或伪报完成。

## 补充入口复核

复查发现旧“生成衍生角色图片”入口会再次扩写已保存的人物设定。现改为优先读取当前结构化模板，避免 Agent 精确修改后又被下一次出图覆盖。新回归将文本推理替换为抛错函数，实际走衍生生成路由，确认图片成功保存且模板、版本和固定种子完全不变。原衍生生成与取消/删除生命周期测试均再次通过。

角色创建入口同时读取同项目已保存角色的指纹，提供给模板扩写作差异对照。补充修改后重新通过类型检查与服务构建；数据库复核仍为全部既有记录未改、新增记录仅属于指定测试项目。
