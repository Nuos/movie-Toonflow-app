# Toonflow 提示词、语义锚点与图片复现

入口：Toonflow 左侧「提示词与复现」，或 http://127.0.0.1:10588/prompt-studio.html 。从已选项目进入会带入项目名称；返回入口为「我的项目」，避免直接进入没有项目上下文的制作页面。

## 人物四视图

新建人物默认**成年女性**，可手动改性别。已有人物不会被改成女性。

四视图统一为一张横幅 2×2：正面全身、左侧面全身、背面全身、面部正面近景。前三格头脚完整、同等人物尺度；四格保持同一张脸、发型、服装和配饰，统一背景与照明。

内置三种风格，每种有三套可展开和复制的完整提示词：

| 风格 | 基准要求 |
|---|---|
| 超真实 | 真实皮肤、毛孔、发丝与人体比例；现代简洁服饰；自然摄影质感 |
| 古装 | 写实古装影视定妆；交领长裙、发髻、玉簪；真实丝麻纹理 |
| 玄幻 | 东方玄幻电影质感；轻甲与长裙、玉石发冠、低强度灵纹；面部与服装结构清晰 |

操作：选择项目 → 四视图人物模板 → 填人物名称、风格、性别与可选描述 → 创建人物资产与三组提示词。此步只创建文字和资产记录。之后到「塑角造景」选择该资产生成图片。

## 三套方案与固定锚点

人物、场景、道具、分镜图和视频切片分别保存版本。每个目标固定六个字段：主体、风格、构图、连续性、允许变化、禁止变化。三套方案共享这些字段：

- A 忠实复现：保留基准构图与细节，视频按原动作顺序均匀推进。
- B 细节表现：图像细化原有材质；视频强调原动作的蓄力与受力细节。
- C 节奏变化：图像仅做允许的微小变化；视频调整起步、主动作和收尾节奏。

场景要求保留机位、透视、地形/建筑布局、地平线、前中后景、关键物件位置，场景资产图不新增人物。已有参考图优先确定实际构图。

视频三套均保留源对白、事件顺序、动作结果与总时长。H3 普通模式输出三字段格式；多参考模式输出六字段格式，保留 Picture、Subject、Video、Audio 引用。每个已有切片均可在面板查看、复制和采用三套方案。

“采用此组”只更新原资产/轨道的提示词，不生成图片或视频。回到原页面刷新后使用。保存锚点会创建新版本；更新已生成的完整提示词时会拆回正文，避免重复包裹。

原单次/批量视频提示词生成接口也会保存三套方案；分镜写入时建立对应视频方案；轨道时长变化会更新方案。没有描述的空轨道显示待补充，不妨碍原工作台打开。模型、画幅、参考素材等配置改变后面板会提示更新。

## 图片复现

图片生成前保存参数，生成成功后记录实际输出校验值：

- 完整提示词、固定种子、尺寸、画幅和有序参考图原始字节。
- 主体/风格/构图锚点及版本。
- 原始 ComfyUI API 工作流：模型名称、采样器、步数、CFG、调度器、随机种子等。
- 冻结参考图及 SHA-256；工作流和输出图片 SHA-256。
- 模型文件路径、大小、mtime 指纹。模型文件发生变化时阻止旧图复现。

新图片自动记录；首次生成的成功图片自动成为该目标基准。资产重绘前先冻结旧基准，再建立新图片占位；失败时恢复原选图。

复现操作：选择目标 → 图片复现记录 → **校验复现资料** → 按需选择 **按原参数复现图片**。校验不调用模型；复现按钮明确提示将使用 GPU。复现只修改工作流的输入文件路径与输出前缀，保留其他执行参数，输出独立候选，不替换当前资产图。

历史图只在输出文件 SHA-256 与本地原始任务完全匹配时关联复现记录。历史模型指纹是在迁移时采集，不冒充原任务当时记录。不同运行库或硬件可能带来微小数值差异；此功能不声称跨环境逐像素一致。固定参考、主体、框架和风格用于约束允许的小幅变化。

复现原始请求保存在私有数据目录 `data/reproduction/`，不包含模型 API 密钥；HTTP 接口受 Toonflow 原有认证保护。
