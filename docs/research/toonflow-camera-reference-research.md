## 3. 建议的使用流程（本次原创产品方案）

### 同一分镜的变体卡片

在现有分镜详情、分镜图和视频提示词入口共用「镜头方案」面板；以分镜 ID 绑定同一组候选。

1. 先确定这一镜的叙事目标，如强调反应、交代环境、追随行动、揭示资讯、建立人物关系。
2. 保留该镜角色、服装、场景、动作事件、关键道具与时间顺序，生成或从模板加入 3–6 个候选。
3. 每张卡直接显示「名称、观众先看到什么→最后看到什么、叙事作用、生成难度、待补栏位」。
4. 展开查看和修改景别、角度、运动方向、速度、幅度、时长、焦点起止与首尾构图。
5. 分别预览「分镜图提示词」「视频提示词」「审计」，可复制、保存为模板、选为本镜方案。
6. 套用后写入既有生成流程，保留其他候选；再次生成候选不能清除使用者正在编辑的提示词。

### 已有分镜图时的两种有用操作

- **沿用目前首帧**：只设计从现有图出发的运动。文字可查出明显矛盾，但图像是否真符合起始态需图像审阅；不得以纯文字规则声称验证了图片。
- **重设首帧构图**：需要从正面改到背面、低位改到俯视、单人改到过肩等情况，另产生分镜图提示词候选，并清楚展示该方案将更换参考图。

### 比较要看叙事差异

同镜候选不能只是「慢推、稍快推、很快推」的同义改写。建议初始方案为「稳定观察」「靠近情绪」「拉远揭示」「侧移关系」四个不同功能，依故事删改。没有叙事动机的炫技镜头不应因为复杂就排到推荐首位。

## 4. 最小可持久化资料结构

这是建议 schema，不要求额外储存重复人物或整段剧本；既有栏位可以引用。

```ts
type CameraVariant = {
  id: string;
  storyboardId: number | string;
  name: string;
  source: 'template' | 'manual' | 'ai';
  templateId?: string;
  intent: string;
  referenceMode: 'keep-first-frame' | 'new-composition';
  shotSize: string;
  angle: string;
  composition: string;
  movement: string;
  direction: string;
  speed: 'slow' | 'normal' | 'fast';
  intensity: 'subtle' | 'moderate' | 'large';
  durationSec: number;
  startFrame: string;
  endFrame: string;
  subjectAction: string;
  environmentMotion?: string;
  focusFrom?: string;
  focusTo?: string;
  continuity: string[];
  imagePrompt: string;
  videoPrompt: string;
  negativePrompt?: string;
  providerProfile?: string;
  status: 'draft' | 'selected' | 'archived';
  updatedAt: string;
};
```

单一移动加速度/方向最容易操作；复合动作另开时间段阵列，不让「固定＋环绕＋推拉」成为平铺词串。选用方案可由分镜保存 `selectedCameraVariantId`，避免候选各自标记造成同镜多个 selected。

## 5. 可立即使用的原创模板

以下均为本次设计，不是影片或官方提示词的逐字转载。`{{}}` 是产品中的可填栏位；UI 要将未填栏位标为待完成，不能把字面占位符发给模型。

| ID / 名称 | 图片提示词应处理的起点 | 视频提示词骨架 | 必须补充的资料 |
| --- | --- | --- | --- |
| locked_observe / 静观反应 | 中近景、视线方向清楚、稳定构图 | 固定机位。{{主体}}完成{{单一动作}}，{{微表情或环境动作}}。焦点持续落在{{主体}}，保留结尾停顿。 | 可见动作，避免把整个片段写成毫无变化 |
| dolly_intimacy / 缓推入情绪 | 中景起始，脸部与靠近路线可见 | 摄影机以{{速度}}朝{{主体}}平稳靠近，从{{起始景别}}收至{{结束景别}}。{{主体动作}}。抵达{{结束焦点}}后停稳。 | 需与图像起始景别一致 |
| pull_reveal / 拉远揭示 | 近景起始，先藏住待揭示资讯 | 从{{可见细节}}开始，摄影机缓慢后移，逐渐露出{{新资讯}}；最后停在{{终点构图}}。{{主体动作}}。 | 被揭示内容、空间关系 |
| lateral_relation / 侧移建立关系 | 主体与可滑移空间，可有前景遮挡 | 摄影机向{{左/右}}平行滑移，从{{起始可见内容}}移到{{终点可见内容}}。前景和背景形成视差，{{主体动作}}。 | 真正横移，不与原地水平摇镜混用 |
| pan_discovery / 原地摇镜发现 | 起点中保留明确寻视方向 | 摄影机保持原位置，朝{{左/右}}平稳转向，由{{起点}}扫至{{发现物}}并停稳。{{主体或环境动作}}。 | 同一空间的方向与终点 |
| arc_relationship / 小弧线换视角 | 半侧面起始，周边空间足够 | 摄影机沿{{方向}}绕{{主体}}移动一小段弧线，从{{起始角度}}抵达{{终止角度}}。{{主体动作}}，结尾保留{{关键关系}}。 | 角度、方向、轴线提示；先小弧再高难度整圈 |
| leading_walk / 正面引领 | 人物前方的全身或中景，后方场景明确 | {{主体}}向前走，摄影机同步后退，保持{{景别}}和主体大小相对稳定。{{环境相对变化}}。 | 主体与摄影机相对方向 |
| following_journey / 背后跟随 | 人物背影与前进通道可见 | 摄影机从{{主体}}后方平稳跟随，穿过{{连续空间}}。{{主体动作}}，结尾停在{{目标或门口}}。 | 通道与终点，避免无意换场 |
| rack_evidence / 拉焦揭示 | 前景证据、背景人物同时在画中 | 固定机位，先对焦{{前景物}}，随后焦点平滑转至{{背景人物}}，让前景柔化。{{背景人物反应}}。 | 两个实际可见且有深度差的焦点对象 |
| crane_scale / 升起展示规模 | 起点主体与其周围环境一致 | 摄影机平稳升高并缓慢后退，从{{人物或细节}}展开至{{环境全貌}}，最后保持{{终点构图}}。 | 新显露环境与起始图一致 |
| dolly_zoom_shock / 空间失衡 | 主体与背景有明显深度，主体居中 | 摄影机向{{主体}}靠近，镜头同步反向变焦，使主体在画中大小近似不变，背景透视逐渐拉开。{{主体反应}}。 | 复合控制，高难度；不做默认方案 |
```

模板栏位不能强制全填。固定机位无需方向/幅度；拉焦需要焦点对象；环绕需要方向和弧度；穿行需要路径。UI 和审计规则要随所选模板显示所需栏位。

## 6. 同分镜对比示例

共同事件：雨夜门口，女子握著未拆的信封，抬眼望向门内。角色、服装、信封、时间和事件都不变。

- **A / 固定观察**：中近景，女子从信封抬眼；焦点跟住眼睛，雨滴在背景落下。观众有时间读表情。
- **B / 缓推情绪**：由中景平稳推近至近景，配合她抬眼，在眼神停住时完成靠近。情绪权重更高。
- **C / 拉远揭示**：由手中信封的近景后移，露出她站在门外与门内空间的距离。需重新设计首帧；不能沿用中景首帧却声称从手部特写开始。
- **D / 前景拉焦**：信封前景清晰、她的脸位于后方；焦点由信封转到抬起的眼睛。需该图具有两个不同深度的可见对象。

以上四个都能服务同一事件，却给不同的观看顺序。展示这个顺序比单纯列英文技术名更有助于使用者选择。

## 7. 审计评估模组

### 分开三类证据

1. **提示词规则检查**：可离线、即时检查栏位、矛盾、占位符、时长和条件。结果称「规则检查」，不能称成片质量。
2. **AI 创作评估**：阅读剧情与候选，评叙事动机、信息次序和相邻镜连续性，附理由和可修改建议。此处才可能使用预设 DeepSeek 文本配置。
3. **生成结果评估**：需要真的读取分镜图/视频才能评身份漂移、轨迹、焦点、遮挡和画面瑕疵。尚未生成或没有视觉能力时标示「未评估」。

### 最有实际价值的规则

| code | 条件 | 严重度 / 修正 |
| --- | --- | --- |
| unresolved_placeholder | 提示词仍含未填模板栏位 | error；提示具体待填栏位 |
| missing_start_or_end | 有揭示/轨迹却缺起止画面 | warning；补明确内容与终点 |
| contradictory_camera | 同时要求完全固定与摄影机空间移动，且没有分时段 | error；选一个主动作或拆段 |
| incompatible_reference | 选沿用首帧，但首景文字与已有构图栏位冲突 | warning；改动态起点或重设首帧；无图像信息时不得声称确认 |
| missing_focus_targets | 选拉焦但未提供起点/终点焦点对象 | error；补两个对象 |
| high_motion_complexity | 短片段中有多段大幅移动和多个人物动作 | warning；缩小幅度、分段或延长时长；不是硬性禁止 |
| continuity_axis_risk | 对话场景大弧环绕或反向跟拍可能越过人物轴线 | warning；要求确认相邻镜视线和左右位置 |
| continuity_subject_drift | 方案更改角色、服装、关键道具或事件 | warning；回到分镜锚点，由使用者决定是否属创作修改 |
| unsupported_profile | 选用的模型配置没有对应负面词或控制能力 | warning；以通用正向描述输出，保留原编辑内容 |
| duration_unknown | 时长缺失、非有限数或超出目前模型范围 | error（数值无效）或 warning（模型范围未知） |
| no_motion_intent | 只有美学形容词，没有具体主体/场景/摄影机动作 | warning；补至少一个可见事件 |

不要用单纯搜寻「固定」和「动」就判定冲突：「固定机位，人物移动」和「固定机位，焦点转移」都合法；Dolly Zoom 的相反方向也是合法设计。需要结构化栏位与句子主语、阶段共同判断。

### 呈现方式

- 显示可执行修正项和其影响的栏位；warning 可以由使用者继续，error 只拦截不能提交的资料。
- 如需分数，命名「提示词准备度」，列出透明项目，例如信息完整、动作可执行、前后连续、模型适配。未检查的项目标 N/A，不能当零分或满分。
- 每次修改方案或所选模型后重新检查，保存 `evaluatedVariantVersion`，旧评估显示过期。
- 人工接受某项风险可记原因；切换另一候选不能继承先前方案的满分或接受状态。

## 8. 本轮实作验收优先序

1. 同分镜新增/比较/保存至少三个不同叙事作用的候选，且能选中一个真正送入原有视频提示词流程。
2. 至少覆盖固定、推、拉、摇、移、跟、弧线、升降、拉焦与特殊变焦；景别和角度分栏。
3. 分镜图与视频提示词分开输出，沿用首帧与新构图有明确行为。
4. 模板可搜索、可预览、可套用，没有未填占位符被直接当成完成品。
5. 规则审计给可操作建议，并且明示没有执行的 AI/视觉评估。
6. 重新整理后仍保留方案、选用状态和提示词；模板变更不覆盖已保存的创作。

本报告没有阅读本地 ai-modulecm；由另一调研分工整合其现有资产可避免重复工作。本报告提出的产品栏位和原创模板可与该内容共同归一化。
